# پینگ‌پنگ — قابلیت نصب + حذف مسابقه | نسخه ۵

نسخهٔ پایه از GitHub `arashlavasani877-creator/pingpong-cup` خوانده و با آن تطبیق داده شده است. `app.js` و `index.html` قبل از ویرایش از نظر Git blob SHA تأیید شده‌اند؛ تنظیم Firebase فعلی و شناسه مدیر ثابت نیز حفظ شده است.

## امکانات تازه
- نصب به صورت PWA در Chrome/Edge/Android؛ راهنمای Add to Home Screen در Safari آیفون.
- آیکون‌های مستقل ۱۹۲، ۵۱۲ و Apple Touch.
- Service Worker فقط صفحه «نیاز به اینترنت» را برای قطعی شبکه نگه می‌دارد؛ عمداً کد Firebase، API و نتایج را کش نمی‌کند تا داده‌های قدیمی نمایش داده نشوند.
- در پنل مدیر، کنار هر مسابقه «حذف مسابقه» اضافه شده است؛ یک Confirm و سپس واردکردن دقیق نام مسابقه لازم است.
- حذف فقط سند همان مسابقه در `tournaments` است و سایر مسابقات و مدیران را تغییر نمی‌دهد؛ حذف برای تماشاگر مجاز نیست.
- از روی Firestore Rules باید حذف را به مدیران مجاز کرد. حذف برگشت‌پذیر نیست؛ پیش از حذف واقعی از مسابقه خروجی JSON بگیرید.

## نصب در GitHub
۱. ZIP را در رایانه استخراج کن. **فایل ZIP را مستقیم در GitHub آپلود نکن.**
۲. در GitHub وارد مخزن `pingpong-cup` شو، از `Add file` گزینه `Upload files` را بزن.
۳. فایل‌های `index.html`, `app.js`, `firebase-config.js`, `manifest.webmanifest`, `pwa.js`, `sw.js`, `offline.html`, `.nojekyll` و پوشه `icons` شامل سه PNG را در ریشه مخزن با حفظ پوشه `icons` قرار بده.
۴. روی `Commit changes` بزن. فایل `original-offline.html` برای پشتیبان است و لازم نیست جایگزین شود.
۵. از مرورگر سایت را دوباره باز کن و Refresh کن. دکمه «نصب اپلیکیشن» در بالای صفحه دیده می‌شود. اگر نصب از مرورگر پشتیبانی شود، پنجره نصب ظاهر می‌شود. در iOS توضیح نصب دستی نمایش داده می‌شود.

## تغییر ضروری قوانین Firestore
۱. به Firebase Console برو، پروژه **Pingpong cup** را انتخاب کن، وارد **Firestore Database → Rules** شو.
۲. **از قوانین فعلی کپی پشتیبان بگیر**؛ سپس فقط قانون بخش `match /tournaments/{roomId}` را اصلاح کن:
   - قبلی: `allow delete: if false;`
   - جدید: `allow delete: if isManager();`
۳. اگر می‌خواهی همه قوانین را کامل جایگزین کنی، فایل `firestore.rules` این بسته را کپی کن و Publish بزن. **اگر قوانین فعلی تغییرات دیگری دارند، روش ویرایش همان یک خط امن‌تر است.**
۴. پس از Publish، حذف فقط برای مدیران فعال می‌شود. تا قبل از آن، دکمه حذف «مجوز ندارید» خواهد داد.

## تست ایمن
- اول یک مسابقه **جدید آزمایشی** بساز؛ همان را از پنل مدیر حذف کن، نه مسابقات واقعی را.
- در مرورگر تماشاگر بدون Refresh باید مسابقه حذف‌شده از فهرست پاک شود.
- دقت کن هیچ تغییری در سندهای `managers` یا `managerRequests` صورت نگیرد.
- برنامه PWA برای دریافت زنده نتایج به اینترنت نیاز دارد و اپ بومی قابل انتشار در فروشگاه‌ها نیست.

## نکته استقرار
این ZIP آماده انتشار است اما به دلیل مجوز نوشتن GitHub (خطای 403)، از این گفتگو مستقیماً روی `main` نصب نشده است. تا زمان آپلود روی GitHub و انتشار Rule، سایت فعال تغییری نمی‌کند.

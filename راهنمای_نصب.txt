نسخه ۶ — رفع نصب اپلیکیشن جام پینگ‌پنگ

۱) این فایل ZIP را روی رایانه Extract / استخراج کن.
۲) در GitHub مخزن arashlavasani877-creator/pingpong-cup و شاخه main را باز کن.
۳) از ریشه مخزن، Add file > Upload files را انتخاب کن.
۴) خود فایل ZIP را آپلود نکن. تمام فایل‌های داخل پوشه استخراج‌شده را به صورت یکجا انتخاب کن و آپلود کن.
۵) فایل‌ها باید کنار index.html در ریشه مخزن باشند، به‌ویژه icon-192.png، icon-512.png و apple-touch-icon.png.
۶) Commit changes را بزن. چند لحظه بعد سایت را در Chrome دوباره باز کن.
۷) Chrome Android: منوی سه‌نقطه > Install app یا از دکمه نصب اپلیکیشن در صفحه استفاده کن.

مهم: این بسته از نسخه فعلی مخزن ساخته شده و تنظیمات Firebase، ورود مدیر، ثبت نتایج و منطق حذف مسابقه را تغییر نمی‌دهد.
این ZIP را مستقیم در GitHub آپلود نکن؛ GitHub Pages خودش ZIP را به فایل‌های سایت تبدیل نمی‌کند.
قوانین Firestore فقط از کنسول Firebase منتشر می‌شوند؛ فایل firestore.rules داخل این ZIP صرفاً مرجع/پشتیبان است.
پوشه اضافی قدیمی PingPong_PWA_Install_Delete_V5 در GitHub ممکن است باقی بماند اما مانع اجرا نیست؛ فعلاً آن را پاک نکن.
